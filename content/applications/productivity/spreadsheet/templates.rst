=========
Templates
=========

In *Documents*, any spreadsheet can be saved as a template. This lets you quickly create
spreadsheets in the future without starting from scratch. For example, you could create a template
for a monthly budget report or a quarterly sales commission report.

.. _templates/create:

Create a template
=================

To create a template from an existing spreadsheet, open the spreadsheet, then click
:menuselection:`File --> Save as template` from the menu bar. Modify the Template Name if necessary
and click :guilabel:`Confirm`.

.. note::
   Templates are available to all users on the database.

.. _templates/manage:

Manage and edit templates
=========================

Manage templates by going to :menuselection:`Documents --> Configuration --> Spreadsheet Templates`.
Remove the :guilabel:`My Templates` :ref:`filter <search/preconfigured-filters>` to view all
templates in the database.

To:

- edit an existing template, click the :icon:`fa-pencil` icon next to the desired template.
- make a copy of an existing template, click the :icon:`fa-clone` icon next to the desired
  template.

Modifications are automatically saved.

.. tip::
   Use the download button under the :guilabel:`Spreadsheet file` column to export a template in
   JSON format. The file can be imported into another database.
